Privacidade e uso de dados

Entenda como funciona o encaminhamento de solicitações deste projeto demonstrativo.

Quais dados são solicitados?

O formulário pode solicitar nome, telefone, endereço, CPF/CNPJ (apenas para serviços), descrição do problema ou produto e quantidade. Os campos variam conforme o tipo de atendimento.

Como esses dados são utilizados?

As verificações de formato são feitas no próprio navegador. O site estático não dispõe de servidor nem banco de dados para guardar esses dados. Após a revisão, a ação “Abrir WhatsApp” cria um link contendo a mensagem preparada com os campos preenchidos.

Importante sobre o WhatsApp

Ao abrir o link, as informações incluídas no texto podem ser transmitidas ao serviço do WhatsApp e constar no histórico ou em registros do navegador. O envio da mensagem só ocorre quando você confirmar no WhatsApp. Evite dispositivos compartilhados e não informe senhas, dados financeiros ou documentos digitalizados.

Limitações de segurança

Este projeto usa validações de interface para reduzir erros de preenchimento, mas não equivale a um sistema transacional com validação em servidor, autenticação, controles de acesso ou política de retenção de dados. Para uso comercial efetivo, a empresa precisa aprovar a coleta de CPF/CNPJ, a finalidade, a base legal e a política de privacidade aplicável, além de confirmar o WhatsApp de destino.
